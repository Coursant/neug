# 02 - Note Structure Design

## 用户问题

如何组织 NeuG 学习笔记目录。

## 处理结果

创建并使用以下结构：

```text
learning/
├── README.md
├── AGENTS.md
├── workflow.md
├── learning-log.md
├── questions.md
├── topics/
├── dialogues/
└── templates/
```

## 形成的决定

- `README.md`: 人类阅读入口。
- `AGENTS.md`: assistant 工作流程。
- `learning-log.md`: 时间线记录。
- `topics/`: 可复用主题笔记。
- `questions.md`: 未解决问题。
